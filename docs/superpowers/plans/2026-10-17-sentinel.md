# Sentinel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Sentinel, a polished single-page fire emergency routing and communication demo with Firefighter and Resident perspectives over one shared, persisted world state.

**Architecture:** One Zustand store (world, comms, ui slices) persists the world and message threads to localStorage. Pure, replaceable functions in `src/lib/` (perception, movement, routing, guidance, priority, camera) derive routes, rankings and instructions from the world through memoized selectors. React components only render state and dispatch store actions; the building drawing (`BuildingView`) and the AR preview (`ARView`) are placeholders behind small prop interfaces.

**Tech Stack:** Vite 5, React 18, TypeScript 5 (strict), Tailwind CSS 3, Framer Motion 11, lucide-react, Zustand 5 (`persist`), Vitest 2 + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-17-sentinel-design.md`

## Global Constraints

- Run with `npm install && npm run dev`. No backend, no network calls besides Google Fonts.
- Colors: ONLY surface #FBF9F6, surface-container #F3F1EE, surface-container-high #ECEAE7, on-surface #1C1B19, on-surface-variant #5F5E5A, outline #C8C6C2, primary #1F4E79, error #B3261E, warning #8A5A00, success #2E6B3F. No gradients. Opacity modifiers of these tokens (e.g. `bg-error/10`) are allowed for tints.
- Type: Inter for UI, JetBrains Mono for numbers, timestamps, coordinates, unit IDs, distances, call signs. Sizes 11/12/14/16/18/24 only. Weights 400/500/600 only. Sentence case; no uppercase tracking.
- Spacing 8px grid, 4px icon gaps. Panel padding 16, section gap 24 (Tailwind `p-4`, `gap-6`).
- Radius: 8 controls, 12 panels/cards, 999 only for status dots.
- Shadow (`shadow-float`) only on floating elements: marker card, dev popover.
- States: hover 8%, focus 12%, pressed 12% on-surface overlay via `.state-layer`; focus ring 2px primary via `.focus-ring`.
- Icons: lucide, size 16 or 20, `strokeWidth={1.75}`, with a text label unless in a tight toolbar.
- Motion: 200ms `cubic-bezier(0.2, 0, 0, 1)`. Nothing bounces or scales past 1.
- Forbidden: emoji, glassmorphism, blur, purple/neon, gradient text, oversized rounded-full buttons, decorative illustrations, lorem ipsum, card drop shadows, AI chatbot.
- Immutability: never mutate state objects; return new objects/arrays.
- Zustand 5: selectors must return existing references (never build new arrays/objects inside a `useSentinel` selector) or React will loop. Derived data goes through `useDerived()`.
- Plan geometry: each floor is 1000 × 300 plan units; hazard grid is 24 columns × 8 rows per floor.
- Commit messages: `<type>: <description>` and end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.

## Review Focus

1. Stale or corrupt localStorage from an earlier build must load the mock incident, not crash. → Task 6 `mergePersisted` tests.
2. A person dragged into the hallway, or standing on floor 1, must still get a sensible route (no skipped legs, no stairs). → Task 4 hallway and floor-1 tests.
3. After a thread is cleared, a resident quick reply must still land and count as unread. → Task 6 clear-then-reply test.
4. Painting many hazard cells must not spam system messages; only a real route change posts one. → Task 6 paint signature test.
5. An evacuated resident must never be told to shelter, even with the Stay override, and has no route. → Task 5 guidance test; Task 6 "I'm out" test.

## Geometry Reference (used by many tasks)

Per-floor plan, 1000 × 300 units:
- Outer walls: x 40–960, y 20–280. Hallway: x 120–880, y 120–180, centerline y 150.
- Unit columns at x 120 | 310 | 500 | 690 | 880. Top row A–D (y 20–120, center y 70), bottom row E–H (y 180–280, center y 230). Unit center x = column midpoint (215, 405, 595, 785).
- Stair A: x 40–120, entry (120,150), center (80,150), floor-1 exit (10,150). Stair B: x 880–960, entry (880,150), center (920,150), floor-1 exit (990,150).
- Staging: outside Exit B at x 1060 (route start (1060,150), F1). Evacuee spots: `y = 86 + (i % 5) * 40`.
- Scale: 0.05 m per unit, 4 m per floor change, walking 1.2 m/s. Structural-risk regions add 20 m to a path's cost when choosing a stair (reported distance unaffected).
- Drawing: floors stacked F4 (top) → F1, label column 60 units wide, 24-unit gap between floors, 16-unit top/bottom padding, 120-unit staging column. viewBox 1180 × 1304.

```json
  }
```

```ts
  const floor = Number(unit[0])
  const letter = unit.slice(1)
  if (!isFloor(floor)) throw new Error(`Unknown unit: ${unit}`)
  const top = (TOP_LETTERS as readonly string[]).indexOf(letter)

  const bottom = (BOTTOM_LETTERS as readonly string[]).indexOf(letter)
```

```ts
import type { Floor, HazardGrid, HazardValue, Point } from '../types'
import { PLAN_H, PLAN_W, type XY } from './geometry'

export const GRID_COLS = 24
export const GRID_ROWS = 8
export const CELL_W = PLAN_W / GRID_COLS
export const CELL_H = PLAN_H / GRID_ROWS
const SAMPLE_STEP = 10

export type Cell = { col: number; row: number }

const clamp = (v: number, lo: number, hi: number) => Math.min(Math.max(v, lo), hi)

export function cellAt(x: number, y: number): Cell {
  return {
    col: clamp(Math.floor(x / CELL_W), 0, GRID_COLS - 1),
    row: clamp(Math.floor(y / CELL_H), 0, GRID_ROWS - 1),
  }
}

export function cellIndex(col: number, row: number): number {
  return row * GRID_COLS + col
}

export function emptyGrid(): HazardGrid {
  const blank = () => new Array<HazardValue>(GRID_COLS * GRID_ROWS).fill(0)
  return { 1: blank(), 2: blank(), 3: blank(), 4: blank() }
}

export function hazardAt(grid: HazardGrid, p: Point): HazardValue {
  const { col, row } = cellAt(p.x, p.y)
  return grid[p.floor][cellIndex(col, row)] ?? 0
}

export function withCell(grid: HazardGrid, floor: Floor, col: number, row: number, value: HazardValue): HazardGrid {
  const i = cellIndex(col, row)
  if (grid[floor][i] === value) return grid
  const cells = grid[floor].slice()
  cells[i] = value
  return { ...grid, [floor]: cells }
}

/** Inclusive column and row ranges. */
export function fillCells(
  grid: HazardGrid,
  floor: Floor,
  cols: [number, number],
  rows: [number, number],
  value: HazardValue,
): HazardGrid {
  let next = grid
  for (let row = rows[0]; row <= rows[1]; row++) {
    for (let col = cols[0]; col <= cols[1]; col++) next = withCell(next, floor, col, row, value)
  }
  return next
}

export function maxHazardAlong(grid: HazardGrid, floor: Floor, a: XY, b: XY): HazardValue {
  const steps = Math.max(1, Math.ceil(Math.hypot(b.x - a.x, b.y - a.y) / SAMPLE_STEP))
  let max: HazardValue = 0
  for (let i = 0; i <= steps; i++) {
    const t = i / steps
    const v = hazardAt(grid, { floor, x: a.x + (b.x - a.x) * t, y: a.y + (b.y - a.y) * t })
    if (v > max) max = v
    if (max === 2) break
  }
  return max
}
```

```ts
import type { Point } from '../types'

const pad = (n: number) => String(n).padStart(2, '0')

export function formatClock(ts: number): string {
  const d = new Date(ts)
  return `${pad(d.getHours())}:${pad(d.getMinutes())}:${pad(d.getSeconds())}`
}

export function formatElapsed(ms: number): string {
  const t = Math.max(0, Math.floor(ms / 1000))
  return `${pad(Math.floor(t / 3600))}:${pad(Math.floor((t % 3600) / 60))}:${pad(t % 60)}`
}

export function formatAgo(ts: number, now: number): string {
  const s = Math.max(0, Math.round((now - ts) / 1000))
  if (s < 45) return 'just now'
  const m = Math.round(s / 60)
  if (m < 60) return `${m} min ago`
  return `${Math.floor(m / 60)} h ago`
}

export function formatDistance(m: number): string {
  return `${Math.round(m)} m`
}

export function formatEta(s: number): string {
  const t = Math.max(0, Math.round(s))
  return `${Math.floor(t / 60)}:${pad(t % 60)}`
}

export function formatCoords(p: Point): string {
  return `F${p.floor} · ${Math.round(p.x)}, ${Math.round(p.y)}`
}

const EMPHASIS = /(\b[A-Z]{2,}(?: [A-Z]\b)?)/

/** Splits instruction text so uppercase keywords (RIGHT, STAIR B) can be emphasized. */
export function splitEmphasis(text: string): { text: string; strong: boolean }[] {
  return text
    .split(EMPHASIS)
    .map((part, i) => ({ text: part, strong: i % 2 === 1 }))
    .filter((part) => part.text.length > 0)
}
```

```ts
/**
 * Stub router. Replace with real pathfinding; keep these signatures.
 * Walks a fixed waypoint graph: unit door → hallway → stairwell → down → exit.
 * Fire (not smoke) on any leg after the person's own doorway blocks that stair.
 */
import type { Floor, Person, Point, Route, StairId, World } from '../types'
import {
  FLOOR_CHANGE_M,
  HALL,
  METERS_PER_UNIT,
  STAGING,
  STAIRS,
  WALK_SPEED_MPS,
  doorFor,
  isAtStaging,
  pointOn,
  unitAt,
} from './geometry'
import { hazardAt, maxHazardAlong } from './grid'

export const STRUCTURAL_PENALTY_M = 20
const STAIR_IDS: readonly StairId[] = ['A', 'B']

const round1 = (n: number) => Math.round(n * 10) / 10

function samePoint(a: Point, b: Point): boolean {
  return a.floor === b.floor && a.x === b.x && a.y === b.y
}

function dedupe(points: Point[]): Point[] {
  return points.filter((p, i) => i === 0 || !samePoint(p, points[i - 1]))
}

export function exitPath(person: Person, stair: StairId): Point[] {
  const { floor } = person.pos
  const s = STAIRS[stair]
  const door = doorFor(person.pos)
  const descent: Point[] = []
  for (let f = floor - 1; f >= 1; f--) descent.push(pointOn(f as Floor, s.center))
  return dedupe([
    person.pos,
    pointOn(floor, door),
    pointOn(floor, { x: door.x, y: HALL.y }),
    pointOn(floor, s.entry),
    pointOn(floor, s.center),
    ...descent,
    pointOn(1, s.exit),
  ])
}

export function pathLengthM(points: Point[]): number {
  let total = 0
  for (let i = 1; i < points.length; i++) {
    const a = points[i - 1]
    const b = points[i]
    total +=
      a.floor === b.floor
        ? Math.hypot(b.x - a.x, b.y - a.y) * METERS_PER_UNIT
        : Math.abs(a.floor - b.floor) * FLOOR_CHANGE_M
  }
  return total
}

export function isPathBlocked(points: Point[], world: World): boolean {
  // Someone inside a unit is already in that room; only legs from the doorway on can block them.
  const start = unitAt(points[0]) ? 2 : 1
  for (let i = start; i < points.length; i++) {
    const a = points[i - 1]
    const b = points[i]
    if (a.floor === b.floor) {
      if (maxHazardAlong(world.hazards, a.floor, a, b) === 2) return true
    } else if (hazardAt(world.hazards, b) === 2) {
      return true
    }
  }
  return false
}

function structuralPenaltyM(points: Point[], world: World): number {
  const inside = (p: Point) =>
    world.structural.some((r) => r.floor === p.floor && p.x >= r.x && p.x <= r.x + r.w && p.y >= r.y && p.y <= r.y + r.h)
  return points.some(inside) ? STRUCTURAL_PENALTY_M : 0
}

type Candidate = { stair: StairId; points: Point[]; blocked: boolean; lengthM: number; cost: number }

function bestCandidate(person: Person, world: World): Candidate {
  const candidates = STAIR_IDS.map((stair): Candidate => {
    const points = exitPath(person, stair)
    const lengthM = pathLengthM(points)
    return { stair, points, blocked: isPathBlocked(points, world), lengthM, cost: lengthM + structuralPenaltyM(points, world) }
  }).sort((a, b) => a.cost - b.cost)
  return candidates.find((c) => !c.blocked) ?? candidates[0]
}

function noRoute(personId: string, kind: Route['kind']): Route {
  return { personId, kind, points: [], via: null, blocked: false, distanceM: 0, etaS: 0 }
}

function hasLeft(person: Person): boolean {
  return person.status === 'evacuated' || isAtStaging(person.pos)
}

export function routeFor(person: Person, world: World): Route {
  if (hasLeft(person)) return noRoute(person.id, 'exit')
  const best = bestCandidate(person, world)
  return {
    personId: person.id,
    kind: 'exit',
    points: best.points,
    via: best.stair,
    blocked: best.blocked,
    distanceM: round1(best.lengthM),
    etaS: Math.round(best.lengthM / WALK_SPEED_MPS),
  }
}

export function entryRouteFor(person: Person, world: World): Route {
  if (hasLeft(person)) return noRoute(person.id, 'entry')
  const best = bestCandidate(person, world)
  const inbound = best.points.slice(0, -1).reverse()
  const crossover = best.stair === 'A' ? [pointOn(1, STAIRS.B.entry), pointOn(1, STAIRS.A.entry)] : []
  const points = dedupe([STAGING, pointOn(1, STAIRS.B.exit), ...crossover, ...inbound])
  const lengthM = pathLengthM(points)
  return {
    personId: person.id,
    kind: 'entry',
    points,
    via: best.stair,
    blocked: false,
    distanceM: round1(lengthM),
    etaS: Math.round(lengthM / WALK_SPEED_MPS),
  }
}

export function getRescueRoutes(world: World): Route[] {
  return world.people
    .filter((p) => p.priority === 'critical' && p.status !== 'evacuated')
    .map((p) => entryRouteFor(p, world))
}

export function sameFloorLegM(route: Route): number {
  const pts = route.points
  if (pts.length === 0) return 0
  const end = pts.findIndex((p) => p.floor !== pts[0].floor)
  return round1(pathLengthM(end === -1 ? pts : pts.slice(0, end)))
}
```

```ts
/** Stub guidance. Turns a route into at most 4 plain-language lines. Replace freely. */
import type { Floor, HazardGrid, HazardValue, Instruction, InstructionMode, Person, Route, World } from '../types'
import { STAIRS, doorFor, unitAt } from './geometry'
import { maxHazardAlong } from './grid'

const ALL_FLOORS: Floor[] = [1, 2, 3, 4]

export function fireFloors(world: World): Floor[] {
  return ALL_FLOORS.filter((f) => world.hazards[f].some((v) => v === 2))
}

function joinFloors(floors: Floor[]): string {
  if (floors.length <= 1) return String(floors[0] ?? '')
  return `${floors.slice(0, -1).join(', ')} and ${floors[floors.length - 1]}`
}

export function turnDirection(person: Person, route: Route): 'LEFT' | 'RIGHT' | null {
  if (!route.via) return null
  return STAIRS[route.via].entry.x >= doorFor(person.pos).x ? 'RIGHT' : 'LEFT'
}

/** Worst hazard along the route on the person's own floor, from their doorway on. */
export function hallwayHazard(person: Person, route: Route, grid: HazardGrid): HazardValue {
  const pts = route.points
  let max: HazardValue = 0
  for (let i = unitAt(person.pos) ? 2 : 1; i < pts.length; i++) {
    const a = pts[i - 1]
    const b = pts[i]
    if (a.floor !== person.pos.floor || b.floor !== person.pos.floor) break
    const v = maxHazardAlong(grid, a.floor, a, b)
    if (v > max) max = v
  }
  return max
}

export function instructionMode(person: Person, route: Route): InstructionMode {
  if (person.status === 'evacuated' || (route.via === null && !route.blocked)) return 'out'
  return route.blocked ? 'stay' : 'go'
}

export function instructionsFor(person: Person, route: Route, world: World): Instruction[] {
  const mode = instructionMode(person, route)
  if (mode === 'out') {
    return [
      { text: 'You are out of the building.', tone: 'go' },
      { text: 'Stay at the staging area by EXIT B.', tone: 'info' },
      { text: 'Tell a responder if anyone is missing.', tone: 'info' },
    ]
  }
  if (mode === 'stay') {
    return [
      { text: 'Both stairs are blocked.', tone: 'stay' },
      { text: 'Close your door. Seal gaps with towels.', tone: 'stay' },
      { text: 'Go to a window and signal.', tone: 'stay' },
      { text: `Responders know you are in ${person.unit}.`, tone: 'info' },
    ]
  }
  const fires = fireFloors(world)
  const clear = hallwayHazard(person, route, world.hazards) === 0
  const dir = turnDirection(person, route)
  return [
    { text: fires.length ? `Fire on floor ${joinFloors(fires)}.` : 'No fire reported near you.', tone: 'info' },
    { text: clear ? 'Your hallway is clear.' : 'Smoke in your hallway. Stay low.', tone: clear ? 'go' : 'info' },
    {
      text: person.pos.floor === 1 ? `Turn ${dir}, go to EXIT ${route.via}.` : `Turn ${dir}, take STAIR ${route.via} down.`,
      tone: 'go',
    },
    { text: 'Do not use the elevator.', tone: 'info' },
```

```ts
/** Stub movement: evacuating people walk their exit route a fixed distance per step. Replace with fire-aware logic. */
import type { Person, Point, World } from '../types'
import { stagingSpot } from './geometry'
import { pathLengthM, routeFor } from './routing'

export const STEP_DISTANCE_M = 8

export function advanceAlong(points: Point[], distanceM: number): { pos: Point; done: boolean } {
  let remaining = distanceM
  for (let i = 1; i < points.length; i++) {
    const a = points[i - 1]
    const b = points[i]
    const len = pathLengthM([a, b])
    if (len >= remaining) {
      if (a.floor !== b.floor) return { pos: remaining >= len / 2 ? b : a, done: false }
      const t = len === 0 ? 1 : remaining / len
      return { pos: { floor: a.floor, x: a.x + (b.x - a.x) * t, y: a.y + (b.y - a.y) * t }, done: false }
    }
    remaining -= len
  }
  return { pos: points[points.length - 1], done: true }
}

export function stepPeople(world: World, now: number = Date.now()): Person[] {
  let evacuated = world.people.filter((p) => p.status === 'evacuated').length
  return world.people.map((person) => {
    if (person.status !== 'evacuating') return person
    const route = routeFor(person, world)
    if (route.blocked || route.points.length < 2) return person
    const { pos, done } = advanceAlong(route.points, STEP_DISTANCE_M)
    if (!done) return { ...person, pos, lastUpdate: now }
    const spot = stagingSpot(evacuated)
    evacuated += 1
    return { ...person, status: 'evacuated', priority: 'safe', pos: spot, lastUpdate: now }
  })
}
```

```ts
import type { Message, Route, Status, Thread, World } from '../types'
import { threadIdFor } from '../data/mock'
import { STATUS_LABEL, SYSTEM_SENDER } from '../lib/labels'
import { routeFor } from '../lib/routing'

let sequence = 0

export function newMessageId(now: number): string {
  sequence += 1
  return `m-${now.toString(36)}-${sequence}`
}

export function systemMessage(personId: string, text: string, now: number): Message {
  return { id: newMessageId(now), threadId: threadIdFor(personId), from: 'system', sender: SYSTEM_SENDER, text, at: now }
}

export function statusMessage(personId: string, status: Status, now: number): Message {
  return systemMessage(personId, `Status changed to ${STATUS_LABEL[status]}`, now)
}

function describeRouteChange(prev: Route, next: Route): string | null {
  if (next.via === null) return null
  if (next.blocked && !prev.blocked) return 'Route blocked · Shelter in place'
  if (!next.blocked && prev.blocked) return `Route open · Take Stair ${next.via}`
  if (!next.blocked && prev.via !== null && prev.via !== next.via) return `Route updated · Stair ${prev.via} → Stair ${next.via}`
  return null
}

export function routeChangeMessages(prev: World, next: World, now: number): Message[] {
  const messages: Message[] = []
  for (const person of next.people) {
    const before = prev.people.find((p) => p.id === person.id)
    if (!before) continue
    const text = describeRouteChange(routeFor(before, prev), routeFor(person, next))
    if (text) messages.push(systemMessage(person.id, text, now))
  }
  return messages
}

/** Appends messages to their threads. Resident messages count as unread for responders. */
export function appendMessages(threads: Thread[], messages: Message[]): Thread[] {
  if (messages.length === 0) return threads
  return threads.map((t) => {
    const mine = messages.filter((m) => m.threadId === t.id)
    if (mine.length === 0) return t
    return {
      ...t,
      messages: [...t.messages, ...mine],
      unread: t.unread + mine.filter((m) => m.from === 'resident').length,
    }
  })
}
```

```ts
import type { Person, QuickReply, World } from '../types'
import { stagingSpot } from '../lib/geometry'

export function applyQuickReply(person: Person, reply: QuickReply, world: World, now: number): Person {
  switch (reply) {
    case 'trapped':
      return { ...person, status: 'trapped', priority: 'critical', lastUpdate: now }
    case 'cant-move':
      return {
        ...person,
        status: 'immobile',
        priority: 'critical',
        mobility: person.mobility.includes('Immobile') ? person.mobility : [...person.mobility, 'Immobile'],
        lastUpdate: now,
      }
    case 'out': {
      if (person.status === 'evacuated') return { ...person, lastUpdate: now }
      const spot = stagingSpot(world.people.filter((p) => p.status === 'evacuated').length)
      return { ...person, status: 'evacuated', priority: 'safe', pos: spot, lastUpdate: now }
    }
  }
```

```ts
import type { Floor, HazardValue, Message, Person, Point, World } from '../types'
import { isInsideBuilding } from '../lib/geometry'
import { withCell } from '../lib/grid'
import { stepPeople } from '../lib/movement'
import { appendMessages, routeChangeMessages, statusMessage } from './events'
import type { SliceCreator } from './types'

export type WorldSlice = {
  world: World
  /** Single entry point for world changes: stores the world and posts system events. */
  commitWorld: (next: World, messages?: Message[]) => void
  movePerson: (id: string, pos: Point) => void
  paintCell: (floor: Floor, col: number, row: number, value: HazardValue) => void
  stepSim: () => void
}

export const createWorldSlice =
  (initial: World): SliceCreator<WorldSlice> =>
  (set, get) => ({
    world: initial,

    commitWorld: (next, messages = []) => {
      const now = Date.now()
      set((s) => ({
        world: next,
        worldUpdatedAt: now,
        threads: appendMessages(s.threads, [...messages, ...routeChangeMessages(s.world, next, now)]),
      }))
    },

    movePerson: (id, pos) => {
      if (!isInsideBuilding(pos)) return
      const { world, commitWorld } = get()
      const person = world.people.find((p) => p.id === id)
      if (!person) return
      const now = Date.now()
      const wasOut = person.status === 'evacuated'
      const moved: Person = wasOut
        ? { ...person, pos, status: 'unknown', priority: 'moderate', lastUpdate: now }
        : { ...person, pos, lastUpdate: now }
      commitWorld(
        { ...world, people: world.people.map((p) => (p.id === id ? moved : p)) },
        wasOut ? [statusMessage(id, 'unknown', now)] : [],
      )
    },

    paintCell: (floor, col, row, value) => {
      const { world, commitWorld } = get()
      const hazards = withCell(world.hazards, floor, col, row, value)
      if (hazards === world.hazards) return
      commitWorld({ ...world, hazards })
    },

    stepSim: () => {
      const { world, commitWorld } = get()
      const now = Date.now()
      const people = stepPeople(world, now)
      const messages = people
        .filter((p, i) => p.status !== world.people[i].status)
        .map((p) => statusMessage(p.id, p.status, now))
      commitWorld({ ...world, people }, messages)
    },
  })
```

```ts
import type { Message, QuickReply, Thread } from '../types'
import { threadIdFor } from '../data/mock'
import { MAX_MESSAGE_LENGTH, QUICK_REPLY_LABEL, RESPONDER_SENDER, residentSender } from '../lib/labels'
import { appendMessages, newMessageId, statusMessage } from './events'
import { applyQuickReply } from './quickReply'
import type { SliceCreator } from './types'

export type CommsSlice = {
  threads: Thread[]
  sendMessage: (threadId: string, from: 'resident' | 'responder', text: string) => void
  sendQuickReply: (personId: string, reply: QuickReply) => void
  clearThread: (threadId: string) => void
  markRead: (threadId: string) => void
}

export const createCommsSlice =
  (initial: Thread[]): SliceCreator<CommsSlice> =>
  (set, get) => ({
    threads: initial,

    sendMessage: (threadId, from, raw) => {
      const text = raw.trim().slice(0, MAX_MESSAGE_LENGTH)
      if (!text) return
      const { threads, world } = get()
      const thread = threads.find((t) => t.id === threadId)
      if (!thread) return
      const now = Date.now()
      const person = thread.personId ? world.people.find((p) => p.id === thread.personId) : undefined
      const message: Message = {
        id: newMessageId(now),
        threadId,
        from,
        sender: from === 'responder' ? RESPONDER_SENDER : residentSender(person?.unit ?? ''),
        text,
        at: now,
      }
      const touchPerson = person && from === 'resident'
      set({
        threads: appendMessages(threads, [message]),
        world: touchPerson
          ? { ...world, people: world.people.map((p) => (p.id === person.id ? { ...p, lastUpdate: now } : p)) }
          : world,
      })
    },

    sendQuickReply: (personId, reply) => {
      const { world, commitWorld } = get()
      const person = world.people.find((p) => p.id === personId)
      if (!person) return
      const now = Date.now()
      const updated = applyQuickReply(person, reply, world, now)
      const chip: Message = {
        id: newMessageId(now),
        threadId: threadIdFor(personId),
        from: 'resident',
        sender: residentSender(person.unit),
        text: QUICK_REPLY_LABEL[reply],
        quick: reply,
        at: now,
      }
      const messages = updated.status !== person.status ? [chip, statusMessage(personId, updated.status, now)] : [chip]
      commitWorld({ ...world, people: world.people.map((p) => (p.id === personId ? updated : p)) }, messages)
    },

    clearThread: (threadId) =>
      set((s) => ({ threads: s.threads.map((t) => (t.id === threadId ? { ...t, messages: [], unread: 0 } : t)) })),

    markRead: (threadId) => {
      const thread = get().threads.find((t) => t.id === threadId)
      if (!thread || thread.unread === 0) return
      set((s) => ({ threads: s.threads.map((t) => (t.id === threadId ? { ...t, unread: 0 } : t)) }))
    },
  })
```

```ts
import type { GoStay, Message, Person, RankedPerson, Route, Thread, World } from '../types'
import { rank } from '../lib/priority'
import { getRescueRoutes, routeFor } from '../lib/routing'
import { useSentinel } from './index'

export type Derived = {
  exitRoutes: Record<string, Route>
  rescueRoutes: Route[]
  ranked: RankedPerson[]
}

let cache: { world: World; derived: Derived } | null = null

/** Memoized on world identity, so every component shares one computation per world change. */
export function deriveWorld(world: World): Derived {
  if (cache && cache.world === world) return cache.derived
  const exitRoutes = Object.fromEntries(world.people.map((p) => [p.id, routeFor(p, world)]))
  const rescueRoutes = getRescueRoutes(world)
  const derived = { exitRoutes, rescueRoutes, ranked: rank(world, rescueRoutes) }
  cache = { world, derived }
  return derived
}

export function useDerived(): Derived {
  return deriveWorld(useSentinel((s) => s.world))
}

export function usePerson(id: string | null): Person | undefined {
  return useSentinel((s) => (id ? s.world.people.find((p) => p.id === id) : undefined))
}

export function useThread(id: string): Thread | undefined {
  return useSentinel((s) => s.threads.find((t) => t.id === id))
}

export function effectiveRoute(route: Route, override: GoStay): Route {
  return override === 'auto' ? route : { ...route, blocked: override === 'stay' }
}

export function lastResidentMessage(thread: Thread | undefined): Message | undefined {
  return thread?.messages.filter((m) => m.from === 'resident').at(-1)
```

```ts
import { useEffect, type RefObject } from 'react'

/** Calls onDismiss on outside pointer-down or Escape while active. */
export function useDismiss(ref: RefObject<HTMLElement>, active: boolean, onDismiss: () => void) {
  useEffect(() => {
    if (!active) return
    const onPointer = (e: PointerEvent) => {
      if (ref.current && !ref.current.contains(e.target as Node)) onDismiss()
    }
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') onDismiss()
    }
    document.addEventListener('pointerdown', onPointer)
    document.addEventListener('keydown', onKey)
    return () => {
      document.removeEventListener('pointerdown', onPointer)
      document.removeEventListener('keydown', onKey)
    }
  }, [ref, active, onDismiss])
}
```

```ts
/**
 * Maps plan coordinates to the placeholder drawing. Replace together with BuildingGeometry
 * when the real building model arrives.
 */
import { FLOORS, type Floor, type Point } from '../../types'
import { PLAN_H, PLAN_W } from '../../lib/geometry'

export const LABEL_W = 60
export const FLOOR_GAP = 24
export const PAD_Y = 16
export const STAGING_W = 120
export const VIEW_W = LABEL_W + PLAN_W + STAGING_W
export const VIEW_H = PAD_Y * 2 + FLOORS.length * PLAN_H + (FLOORS.length - 1) * FLOOR_GAP

export function floorTop(floor: Floor): number {
  return PAD_Y + (4 - floor) * (PLAN_H + FLOOR_GAP)
}

export function project(p: Point): { x: number; y: number } {
  return { x: LABEL_W + p.x, y: floorTop(p.floor) + p.y }
}

export function unproject(x: number, y: number): Point | null {
  for (const floor of FLOORS) {
    const top = floorTop(floor)
    if (y >= top && y < top + PLAN_H) return { floor, x: x - LABEL_W, y: y - top }
  }
  return null
}

export function clientToSvg(svg: SVGSVGElement, clientX: number, clientY: number): { x: number; y: number } {
  const ctm = svg.getScreenCTM()
  if (!ctm) return { x: 0, y: 0 }
  const p = new DOMPoint(clientX, clientY).matrixTransform(ctm.inverse())
  return { x: p.x, y: p.y }
}
```

```ts
import { FLOORS, type HazardGrid, type OverlayKind, type Region } from '../../types'
import { CELL_H, CELL_W, GRID_COLS, GRID_ROWS, cellIndex } from '../../lib/grid'
import type { OverlayRegion } from './types'

/** Merges horizontal runs of equal hazard cells into rectangles. */
export function hazardsToRegions(
  hazards: HazardGrid,
  structural: Region[],
  enabled: Record<OverlayKind, boolean>,
): OverlayRegion[] {
  const regions: OverlayRegion[] = []
  for (const floor of [...FLOORS].reverse()) {
    const cells = hazards[floor]
    for (let row = 0; row < GRID_ROWS; row++) {
      let col = 0
      while (col < GRID_COLS) {
        const value = cells[cellIndex(col, row)]
        if (value === 0) {
          col += 1
          continue
        }
        let end = col + 1
        while (end < GRID_COLS && cells[cellIndex(end, row)] === value) end += 1
        const kind: OverlayKind = value === 2 ? 'fire' : 'smoke'
        if (enabled[kind]) regions.push({ kind, floor, x: col * CELL_W, y: row * CELL_H, w: (end - col) * CELL_W, h: CELL_H })
        col = end
      }
    }
  }
  if (enabled.structural) regions.push(...structural.map((r) => ({ kind: 'structural' as const, ...r })))
  return regions
}
```

```tsx
        const style = STYLE[path.variant]
        const points = path.points.map((p) => project(p)).map((q) => `${q.x},${q.y}`).join(' ')
        return (
          <motion.polyline
            key={path.id}
            points={points}
            className="stroke-primary"
            strokeWidth={style.width + (path.emphasized ? 1.5 : 0)}
            strokeDasharray={style.dash}
            vectorEffect="non-scaling-stroke"

            initial={{ opacity: 0 }}
            animate={{ opacity: path.dimmed ? 0.25 : 1 }}

          />
        )
      })}
      {paths.map((path) => (path.label ? <PathLabel key={`${path.id}-label`} text={path.label.text} at={path.label.at} /> : null))}
```

```tsx
import { useState, type PointerEvent } from 'react'
import type { Point } from '../../types'
import { PersonMarker } from './PersonMarker'
import { clientToSvg, project, unproject } from './project'
import type { MarkerSpec } from './types'

const DRAG_THRESHOLD = 6

type Drag = { id: string; x: number; y: number; startX: number; startY: number; moved: boolean }

type Props = {
  markers: MarkerSpec[]
  onMarkerClick?: (id: string) => void
  onMarkerDrop?: (id: string, pos: Point | null) => void
}

function svgPoint(e: PointerEvent<SVGGElement>) {
  const svg = e.currentTarget.ownerSVGElement
  return svg ? clientToSvg(svg, e.clientX, e.clientY) : null
}

export function MarkerLayer({ markers, onMarkerClick, onMarkerDrop }: Props) {
  const [drag, setDrag] = useState<Drag | null>(null)
  const ordered = [...markers].sort((a, b) => Number(a.selected || a.emphasized) - Number(b.selected || b.emphasized))

  return (
    <g>
      {ordered.map((m) => {
        const dragging = drag?.id === m.id && drag.moved
        const pos = dragging ? { x: drag.x, y: drag.y } : project(m.pos)
        return (
          <PersonMarker
            key={m.id}
            spec={m}
            x={pos.x}
            y={pos.y}
            dragging={dragging}
            onActivate={() => onMarkerClick?.(m.id)}
            onPointerDown={(e) => {
              if (!m.draggable) return
              const p = svgPoint(e)
              if (!p) return
              e.currentTarget.setPointerCapture(e.pointerId)
              setDrag({ id: m.id, x: p.x, y: p.y, startX: p.x, startY: p.y, moved: false })
            }}
            onPointerMove={(e) => {
              if (!drag || drag.id !== m.id) return
              const p = svgPoint(e)
              if (!p) return
              const moved = drag.moved || Math.hypot(p.x - drag.startX, p.y - drag.startY) > DRAG_THRESHOLD
              setDrag({ ...drag, x: p.x, y: p.y, moved })
            }}
            onPointerUp={() => {
              if (!drag || drag.id !== m.id) return
              if (drag.moved) onMarkerDrop?.(m.id, unproject(drag.x, drag.y))
              else onMarkerClick?.(m.id)
              setDrag(null)
            }}
          />
        )
      })}
    </g>
  )
}
```

```ts
import type { Route } from '../../types'
import type { PathSpec } from './types'

/** Entry + exit for every critical person, plus the focused person's exit. */
export function buildPaths(rescue: Route[], exits: Record<string, Route>, focusId: string | null): PathSpec[] {
  const flags = (personId: string) => ({ emphasized: personId === focusId, dimmed: focusId !== null && personId !== focusId })
  const specs: PathSpec[] = rescue.map((r) => ({ id: `entry-${r.personId}`, points: r.points, variant: 'entry', ...flags(r.personId) }))
  const exitIds = new Set(rescue.map((r) => r.personId))
  if (focusId) exitIds.add(focusId)
  for (const id of exitIds) {
    const route = exits[id]
    if (!route || route.points.length < 2 || route.blocked) continue
    specs.push({ id: `exit-${id}`, points: route.points, variant: 'exit', ...flags(id) })
  }
  return specs
}
```

```tsx
import { useRef, type PointerEvent } from 'react'
import { FLOORS, type Point } from '../../types'
import { WALL, isInsideBuilding } from '../../lib/geometry'
import { clientToSvg, project, unproject } from './project'

type Props = { onPaint: (p: Point, erase: boolean) => void }

/** Transparent hit areas over each floor that paint hazard cells while the pointer is down. */
export function PaintSurface({ onPaint }: Props) {
  const painting = useRef(false)

  const paintAt = (e: PointerEvent<SVGRectElement>) => {
    const svg = e.currentTarget.ownerSVGElement
    if (!svg) return
    const q = clientToSvg(svg, e.clientX, e.clientY)
    const p = unproject(q.x, q.y)
    if (p && isInsideBuilding(p)) onPaint(p, e.shiftKey)
  }

  return (
    <g>
      {FLOORS.map((floor) => {
        const o = project({ floor, x: WALL.x0, y: WALL.y0 })
        return (
          <rect
            key={floor}
            x={o.x}
            y={o.y}
            width={WALL.x1 - WALL.x0}
            height={WALL.y1 - WALL.y0}
            className="cursor-crosshair fill-transparent"
            onPointerDown={(e) => {
              e.currentTarget.setPointerCapture(e.pointerId)
              painting.current = true
              paintAt(e)
            }}
            onPointerMove={(e) => {
              if (painting.current) paintAt(e)
            }}
            onPointerUp={() => {
              painting.current = false
            }}
          />
        )
      })}
    </g>
  )
}
```

```tsx
import { IconButton } from '../ui/IconButton'

const MAX_HEIGHT = 128

type Props = { placeholder: string; onSend: (text: string) => void; focusNonce?: number; divider?: boolean }

export function Composer({ placeholder, onSend, focusNonce = 0, divider = true }: Props) {
  const [text, setText] = useState('')
  const ref = useRef<HTMLTextAreaElement>(null)
  const canSend = text.trim().length > 0

  useEffect(() => {
    if (focusNonce > 0) ref.current?.focus()
  }, [focusNonce])

  useLayoutEffect(() => {
    const el = ref.current
    if (!el) return
    el.style.height = 'auto'
    el.style.height = `${Math.min(el.scrollHeight, MAX_HEIGHT)}px`
  }, [text])

  const submit = () => {
    if (!canSend) return
    onSend(text)
    setText('')
  }

  return (
    <form
      onSubmit={(e) => {
        e.preventDefault()
        submit()
      }}
      className={cn('flex shrink-0 items-end gap-2 p-3', divider && 'border-t border-outline')}
    >
      <textarea
        ref={ref}
        rows={1}
        value={text}
        maxLength={MAX_MESSAGE_LENGTH}
        placeholder={placeholder}
        aria-label={placeholder}
        onChange={(e) => setText(e.target.value)}
        onKeyDown={(e) => {
          if (e.key === 'Enter' && !e.shiftKey && !e.nativeEvent.isComposing) {
            e.preventDefault()
            submit()
          }
        }}
        className="focus-ring min-h-10 flex-1 resize-none rounded-8 border border-outline bg-surface px-3 py-2 text-14 placeholder:text-on-surface-variant"
      />
```

```tsx
import { Accessibility, Check, LogOut, TriangleAlert, type LucideIcon } from 'lucide-react'
import { useEffect, useState } from 'react'
import type { QuickReply, Status } from '../../types'
import { cn } from '../../lib/cn'
import { QUICK_REPLY_LABEL } from '../../lib/labels'

const SENT_MS = 1500

const REPLIES: { reply: QuickReply; icon: LucideIcon; status: Status; idle: string; active: string }[] = [
  { reply: 'out', icon: LogOut, status: 'evacuated', idle: 'border-success/40 text-success', active: 'bg-success/10' },
  { reply: 'trapped', icon: TriangleAlert, status: 'trapped', idle: 'border-error/40 text-error', active: 'bg-error/10' },
  { reply: 'cant-move', icon: Accessibility, status: 'immobile', idle: 'border-warning/40 text-warning', active: 'bg-warning/10' },
]

type Props = { current: Status; onReply: (reply: QuickReply) => void }

export function QuickReplies({ current, onReply }: Props) {
  const [sent, setSent] = useState<QuickReply | null>(null)

  useEffect(() => {
    if (!sent) return
    const id = window.setTimeout(() => setSent(null), SENT_MS)
    return () => window.clearTimeout(id)
  }, [sent])

  return (
    <div role="group" aria-label="Quick replies" className="grid shrink-0 grid-cols-3 gap-2 border-t border-outline px-3 pt-3">
      {REPLIES.map(({ reply, icon: Icon, status, idle, active }) => {
        const isSent = sent === reply
        const ShownIcon = isSent ? Check : Icon
        return (
          <button
            key={reply}
            type="button"
            aria-pressed={current === status}
            onClick={() => {
              onReply(reply)
              setSent(reply)
            }}
            className={cn(
              'state-layer focus-ring flex h-12 items-center justify-center gap-2 rounded-8 border bg-surface text-14 font-semibold',
              idle,
              current === status && active,
            )}
          >
            <ShownIcon size={20} strokeWidth={1.75} aria-hidden />
            {isSent ? 'Sent' : QUICK_REPLY_LABEL[reply]}
          </button>
        )
      })}
    </div>
  )
}
```
